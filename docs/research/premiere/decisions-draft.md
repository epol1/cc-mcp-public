# pr-cut decisions (draft, to append to docs/DECISIONS.md with numbers after Phase 6's)

| # | Decision | Why |
|---|---|---|
| PR1 | **Bridge = CEP + ExtendScript** (`packages/bridge-cep-pr`, port 47812, same token/eval design as AE). A UXP plugin is optional and long-polls the CEP hub (`/uxp/next`, `/uxp/result`). | CEP still loads in Premiere 26.5.2 with a background `StartOn` extension and needs no setup (PlayerDebugMode was on); UXP plugins can't listen and need Developer Mode. |
| PR2 | **Build path = FCP7 XML in Premiere's own dialect** (exploded stereo pairs with `currentExplodedTrackIndex`, `pproTicksIn/Out`, transitions with −1 edges, Audio Levels `<when>` in source frames, Lumetri from Premiere's filter block). Live ExtendScript only for mogrt fields and caption tracks. | Verified: frame exact at 6 rates, one undo step, never touches existing sequences, reuses master clips. ExtendScript live edits cost an undo entry each and property writes aren't undoable. |
| PR3 | **Edit plans are JSON**, not TSX. | Cuts are data; agents write and diff JSON easily; validated by zod before Premiere is touched. |
| PR4 | **Transcription = local faster-whisper large-v3-turbo** (Python 3.12 venv, CUDA wheels, ffmpeg decode, a disfluent prompt so fillers survive), cached by content hash; **word boundaries refined to audio energy**. | Premiere's Speech to Text is Whisper-based too but not reachable from ExtendScript (UXP pending). Measured: Whisper places word starts 0.2–0.3 s early, ~1 s after long pauses; refinement brings them within ~0.08 s, so cuts don't clip onsets. |
| PR5 | **Edits create versions by adopting Premiere's XML export** of the sequence (filters and graphics carried verbatim; empty audio filters Premiere exports are dropped; captions rebuilt). | The user's rule (never modify originals) and one undo per batch, with nothing lost that Premiere's own round trip keeps. |
| PR6 | **Undo steps back to the batch's starting undo index, never by count**, checking the batch's project stays in focus. | One XML import moves QE's undo index by ~12 but one undo reverts it; stepping by count would undo older work. Premiere can switch focus when an undo removes the open sequence. |
| PR7 | **Loudness = clone + Amplify + Hard Limiter (true peak) per audio clip**, gain found by measurement (secant), per-clip ceiling lowered by the measured overshoot. Parameters are normalized: Amplify/Input Boost −60…+30 dB (measured). | The master track is unreachable from scripts and clip Volume runs after standard effects. Verified −14.5 LUFS / −1.0 dBTP on a mixed cut. |
| PR8 | **Social versions = Premiere Auto Reframe sequences**, exported at native size and scaled with ffmpeg to 1080×1920 / 1080×1080 / 1080×1350. | `.epr` frame sizes sit behind an opaque match-source flag; Auto Reframe keeps an editable, subject-tracked sequence and carries captions. |
| PR9 | **Media library = node:sqlite + FTS5 (porter)** in `~/.ae-compose/library`, a detached worker, shot descriptions written by the agent via tools. | No native dependency (node:sqlite has FTS5 on 22.20); both tools share it; descriptions need a model, which is the agent itself. |
| PR10 | **Shared cache root `~/.ae-compose/`** for both tools (transcripts, library, pr-cut, bridge info). | One library and transcript cache for AE and Premiere. |
| PR11 | **Premiere suites live in `tests/premiere/` (`pnpm test:pr`)**, in a throwaway test project. | `pnpm test:ae` runs everything under tests/integration and must not need Premiere. |
| PR12 | **Bridge HTTP client uses a fresh connection per request** (`agent: false`). | Node 22 reuses keep-alive sockets; the bridges' CEP Node closes idle ones after 5 s, giving ECONNRESET. |
| PR13 | **The watchdog auto-answers Premiere's FCP "Translation Report"**; runEs watches for dialogs during long calls. | It is informational and otherwise blocks the import call. |
| PR14 | **Worktree `pr-cut` while Phase 6 shares the checkout** (user's choice: core extraction paused until Phase 6 is released, then rebased). | Two sessions in one tree would commit each other's half-finished work (`release.mjs` runs `git add -A`). |
| PR15 | Name stays **pr-cut** (`prc` CLI, `pr-cut` MCP server). | Short, clear next to ae-compose / `aec`. |
